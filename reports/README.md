# Reports & Thesis Artifacts Index

This folder contains thesis-friendly Markdown reports generated by notebooks and reproducibility scripts. The thesis framing is a scoped public-model/private-input proof pattern for verifiable semantic explanations, instantiated in the TON_IoT intrusion detection case study.

Scope guardrail: unless a report explicitly labels an item as appendix evidence or future work, the implemented claim is limited to approved public linear/logistic tabular models with fixed semantic groups and a fixed reference vector. The main Stage 3.4 system is not model-agnostic, does not hide model weights, does not provide differential privacy, and does not bind a private witness to a specific external log event. The optional Stage 3.5 input-commitment prototype is appendix-only and still requires an external trusted commitment registry for real provenance.
