# Reports & Thesis Artifacts Index

This folder contains thesis-friendly Markdown reports generated by notebooks and reproducibility scripts. The thesis framing is a verifiable semantic explanation framework under private inputs, instantiated in the TON_IoT intrusion detection case study.

## Read-this-first

- Repo map (what each stage does + inputs/outputs): `reports/thesis_project_map.md`
- Dataset / protocol summary (Stage 1): `reports/dataset_summary.md`

## Core ML evaluation (thesis-grade)

These reports are generated via the reproducibility runner `tools/reproduce.py`.

- Imbalance-aware baseline metrics + threshold tuning:
  - Report: `reports/baseline_extended_metrics.md`
  - Generator: `python tools/reproduce.py metrics`

- Decision engineering (tradeoff curves, operating points, calibration):
  - Report: `reports/decision_engineering_baselines.md`
  - Figures: `reports/figures/decision_engineering_*`
  - Generator: `python tools/reproduce.py eval`

- Drift / robustness proxy (metric stability across ordered test chunks):
  - Report: `reports/drift_chunks.md`
  - Figures: `reports/figures/drift_chunks_*`
  - Generator: `python tools/reproduce.py drift --chunks 20`

- Semantic-group ablation (raw vs size-normalized group frequency):
  - Report: `reports/semantic_group_ablation.md`
  - Figures: `reports/figures/semantic_group_ablation_*`
  - Generator: `python tools/reproduce.py semantic-groups`

- Semantic-group Exact SHAP (academic explanation extension + Stage 3.4 ZK verification):
  - CSV: `outputs/explainability/exact_shap_semantic_groups.csv`
  - Reports: `reports/exact_shap_semantic_groups.md`, `reports/method_choice_exact_shap.md`
  - Generator: `python tools/eval_exact_shap_semantic_groups.py`
  - ZK status: Stage 3.4 verifies semantic-group Exact SHAP top-3 for the public Logistic Regression model with private input features.

- Cost-based threshold selection (explicit FN/FP cost ratios):
  - Report: `reports/cost_based_thresholds.md`
  - Figures: `reports/figures/cost_thresholds_*`
  - Generator: `python tools/reproduce.py cost --ratios "0.25,0.5,1,2,5,10,20,50,100"`
  - PowerShell note: the `--ratios` value must be quoted.

## One-command regeneration

To regenerate the full ML evaluation pack (recommended for defense/demo):

- `python tools/reproduce.py all-eval --ratios "0.25,0.5,1,2,5,10,20,50,100"`
- Optional: include ZK scaling benchmark with `--include-zk-scale` (takes longer).
